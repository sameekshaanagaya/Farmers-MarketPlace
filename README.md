# Farmer's Marketplace

Farmer's Marketplace is a web-based platform designed to provide a convenient way for farmers to showcase their agricultural products and for customers to discover and purchase products directly from them.

## Features

- Secure user registration and login
- Farmer account and product management
- Add, update, and remove agricultural products
- Browse available farm products
- Search products based on requirements
- View detailed product information
- Organized product listings
- Easy-to-use web interface
- Flask-based backend for handling application logic
- CSV-based data storage and management

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- CSV

## Project Structure

The project follows a Flask-based web application structure. Flask manages the backend functionality and routing, while HTML, CSS, and JavaScript are used to build the frontend interface. CSV files are used for storing and managing application data.

## How to Run

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
cd farmer-marketplace
```
### 2. Install Dependencies
```bash
pip install -r requirements.txt
```
### 3. Start the Application
```bash
python app.py
```
### 4. Open in Browser
Visit:
http://127.0.0.1:5000
